
# NeuralNetworkOptimization

Исследование методов оптимизации нейронных сетей в рамках практической работы № 9 по дисциплине «Математические основы систем анализа данных и искусственного интеллекта».

## Содержание

| Ноутбук                         | Описание                                                                                                                        |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `LBFGS_Neural_Network.ipynb`         | Реализация L-BFGS для обучения нейронной сети в задаче регрессии.                     |
| `Neural_Optimizers_Comparison.ipynb` | Сравнение AdamW, RMSProp, BFGS и GGN в задаче классификации.                                              |
| `Adan_vs_AdamW.ipynb`                | Сравнение качества, устойчивости и вычислительных затрат Adan и AdamW.               |
| `Muon_Modification.ipynb`            | Разработка собственной модификации Blend-Muon, спектральный анализ и ablation study. |

## Основные результаты

- Реализованы и исследованы градиентные, квазиньютоновские и современные методы оптимизации.
- Проведены воспроизводимые эксперименты на синтетических данных.
- Выполнено сравнение качества, сходимости, устойчивости, времени и затрат памяти.
- Предложена модификация Blend-Muon, изменяющая спектральную структуру матричного направления с сохранением нормы Фробениуса.
- Blend-Muon снизил минимальные валидационные потери на 0.96%, однако преимущество на тестовой выборке не подтвердилось.

## Технологии

Python 3.12, NumPy, Pandas, SciPy, PyTorch, Scikit-learn, Matplotlib, Jupyter Notebook.

## Установка и запуск

```bash
python -m venv .venv
```

Активация виртуального окружения в Windows:

```bash
.venv\Scripts\activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
```

Открыть нужный ноутбук в VS Code или Jupyter и последовательно выполнить все ячейки.
